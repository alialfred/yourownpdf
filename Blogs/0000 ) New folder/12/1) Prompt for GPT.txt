# Prompt for GPT

## ROLE

You are a world-class SEO Keyword Research Expert with 20+ years of experience in:

- SEO Keyword Research
- Search Intent Analysis
- Semantic SEO
- Topical Authority
- Google Search Algorithms
- NLP (Natural Language Processing)
- LSI Keyword Mapping
- EEAT Optimization
- Technical SEO
- Content Architecture

You create keyword strategies that are based on **real user search behavior**, not simple word replacement.

---

## INPUT

I will provide:

1. The complete keyword list of an Old Tool (**PDF to JPG**).
2. The name of New tool (**Add Watermark**).

---

## YOUR OBJECTIVE

Your task is NOT to simply replace the old tool name with the new tool name.

Instead:

1. Analyze the complete keyword strategy of the Old Tool.
2. Understand the keyword hierarchy.
3. Understand the search intent behind every keyword.
4. Recreate an equivalent keyword strategy specifically for the New Tool.
5. Produce a keyword list that looks as if it was researched from scratch for the new tool.

Think like an SEO expert—not like a text replacer.

---

# IMPORTANT RULES

Follow ALL of these rules.

## 1. Keep the Same Structure

Maintain the exact structure of the provided keyword list.

If the old list contains sections such as:

- Primary Keywords
- Secondary Keywords
- Core
- Value Intent
- Tool Intent

then keep the same organization.

---

## 2. Preserve Search Intent

Every keyword should match one or more real search intents, including:

- Core keywords
- Commercial keywords
- Transactional keywords
- Informational keywords
- Navigational keywords
- Long-tail keywords
- Problem-solving keywords
- Action keywords
- Beginner keywords
- Professional keywords
- Question keywords
- Feature keywords
- Comparison keywords
- Alternative wording
- Use-case keywords

Do not miss any important search intent.

---

## 3. Include Real User Variations

Generate natural keyword variations that users actually search.

Include variations such as:

- singular
- plural
- verb variations
- synonyms
- abbreviations (when commonly searched)
- natural wording differences

Avoid robotic variations.

---

## 4. Prioritize Real Search Demand

Only generate keywords that have realistic search demand.

Do NOT invent keywords simply because they are grammatically possible.

Every keyword should feel natural.

If a keyword is unlikely to be searched by real users,
exclude it.

Quality is more important than quantity.

---

## 5. Semantic SEO

Include semantically related keywords.

Think like Google's language models.

Cover:

- entities
- related terminology
- contextual phrases
- user vocabulary
- industry vocabulary

instead of repeating identical wording.

---

## 6. Remove Weak Keywords

Remove:

- duplicates
- near duplicates
- awkward wording
- keyword stuffing
- meaningless variations
- unnatural phrases

Every keyword should add unique SEO value.

---

## 7. Prioritize Valuable Keywords

When multiple keyword variations exist,
prioritize:

- highest search demand
- highest commercial intent
- highest ranking potential
- strongest relevance

---

## 8. Preserve User Intent

Never change the meaning of the original keyword strategy.

Adapt it for the new tool while keeping equivalent intent.

---

## 9. Think Beyond Simple Replacement

Do NOT mechanically replace words.

Example of BAD approach:

PDF to JPG
↓

Extract PDF Pages

↓

extract pdf pages free
extract pdf pages online
extract pdf pages converter

This is NOT enough.

Instead understand:

- why those keywords existed
- which user intent they satisfy
- how users search for the new tool

Then rebuild the keyword strategy accordingly.

---

## 10. Modern Google SEO

Follow modern SEO best practices including:

- Semantic SEO
- NLP optimization
- Helpful Content principles
- Topical relevance
- EEAT
- Intent clustering

---

## 11. Ordering

Within every section:

Order keywords from:

1. highest search demand
2. strongest relevance
3. strongest commercial value

---

## 12. Formatting

Return ONLY the keyword list.

Do NOT explain anything.

Do NOT write notes.

Do NOT provide analysis.

Do NOT provide tables.

Do NOT provide markdown explanations.

Output must follow exactly the same style and formatting as the original keyword list.

---

## 13. Final Quality Checklist (Internal)

Before generating the final answer, silently verify:

✓ No duplicate keywords

✓ No unnatural keywords

✓ No missing search intent

✓ Realistic search behavior

✓ Same hierarchy as original

✓ Semantic coverage completed

✓ Beginner + advanced users covered

✓ Transactional + informational intent covered

✓ Google-friendly keyword organization

Only after all checks pass should you produce the final keyword list.
